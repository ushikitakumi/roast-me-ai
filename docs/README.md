# roast-me-ai 設計ドキュメント

更新日: 2026-09-19。アバターの方式を再検討し、3Dアバターの試作と本人評価を先行する方針に変更した。方針決定と実装完了は別。現在のアプリは無料コアループと旧動画スタブで、3D試作は未実装。

## 1. プロダクトと現在の優先事項

本人専用の習慣化アプリ兼、AI/LLMを応用するバックエンドのポートフォリオ。ユーザーと同格のライバルが、宣言と本人の報告の差を突き、本人が達成を宣言したら負けを認める。

**動画ファイルの生成・保存・ダウンロードは初期版の必須条件から外す。画面上の3Dアバターが音声に合わせて喋り、本体統合後は履歴から再生できる体験を目指す。**

次の作業はPCブラウザの専用ページでの無償試作。既存実装は試作中に維持し、本人が見た目と喋り方を確認して採用した後に3D方式へ置き換える。Hedraとの二方式対応は初期版で目指さない。

## 2. 確定した判断

| 論点 | 現行方針 |
|---|---|
| 利用者 | 本人1人、日本語、Basic認証。本番はHTTPS |
| 外見 | 写実寄りの3Dキャラクター1体、胸上、こちらを向く。成人の同年代に見える少し生意気なライバル。実写同等の品質は必須にしない |
| 素材 | 試作は利用条件を確認した無償の既製モデル。無料の範囲で写実性が限定されても、まず動きを評価する |
| 将来 | 自作3Dモデルに差し替える。キャラクター・対応する声の選択UIは将来のまま |
| 動き | 音声に合わせた簡易的な口の開閉、まばたき、小さな顔の動き。無音・停止時は口を閉じる |
| 試作音声 | 約10秒の用意済み日本語音声。中性的で落ち着いた挑発口調。無償素材、有料APIなし |
| 試作画面 | 既存アプリ内の専用ページ。PCブラウザで表示・手動再生・停止・再再生 |
| 採用判断 | 動作テスト後に本人が「ライバルに話しかけられている感覚」を評価。自動で本体移行しない |
| 通常投稿 | 無料定型文を維持。目標・進捗・達成・取りやめのコアループは変更しない |
| 煽りの根拠 | 本人の宣言と報告だけ。実績を捏造せず、順調な日は成果を認める |
| 休養・停止 | 休養自体を責めず、疲労・体調不良だけでは自動停止しない。手動停止と深刻な危険入力による24時間＋明示解除は維持 |
| 強度 | 弱・標準・強。行動だけを対象にし、人格等を攻撃しない |
| 達成 | 本人の宣言を受け入れ、外部AIなしで勝利の定型文。追加課題なし |
| 削除 | 報告と対応・参照先の煽りを非表示。後続報告と発生済み費用は保持 |
| 予算 | 本体の生成費用は月20ドル、日本時間で集計、インフラ別枠。試作は無償で有料呼び出しなし |

## 3. 試作と本体統合の区別

```text
今回の試作:
用意済み音声 → 手動再生 → 音声に合わせて3Dアバターを動かす

採用後に詳細設計する本体:
目標・進捗 → 通常は無料定型文
           → 任意の生成本文・音声 → 3Dアバターで手動再生
保存した履歴・音声 → 履歴から手動再生
```

Spring Boot・Next.js・PostgreSQLは維持する。Three.js + VRM / three-vrm + Web Audio APIは試作の技術候補であり、素材・依存互換性の確認後に選ぶ。引用されていたOpenAI TTS等を採用済みとはしない。LLM・音声生成・ストレージの実接続は試作に含めない。

## 4. 完成の判断

試作のPA1〜PA5は [01](./01-requirements.md) に定義する。試作が合格してもアプリ全体の完成ではない。本体は本人専用環境で、目標作成→報告→任意のアバター発話→履歴再生→達成が使え、認証・安全・削除・費用・復旧の検証を通す必要がある。

旧AC2の動画段階生成、旧AC3の動画受付復旧を新方式の完成条件としてそのまま流用しない。LLM/TTSの契約に合わせた受入条件を試作合格後に定める。既存の動画テストの成功を3D機能の成功と扱わない。

## 5. 範囲外と代替案

- 試作ではLLM/TTS接続、目標画面への統合、履歴連携、スマートフォンの合格保証を行わない。
- 発音ごとの口形、全身ジェスチャー、指差しは試作の必須条件にしない。簡易口パクの評価で必要性を判断する。
- 動画ファイル生成・書き出し、Hedraとの二方式対応は初期版の対象外。
- 怒りゲージ、比較画面、複数ユーザー、課金、SNS、目標・報告編集は引き続き対象外。ユーザー同士の相互煽りは恒久的に対象外。
- AI動画生成から3D方式へ進む理由は、ファイル生成より「画面上で喋る体験」を優先するため。実際の表示品質・性能は未検証であり、必ず安い・自然・高速とは保証しない。
