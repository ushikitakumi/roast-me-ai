# API設計と移行方針

> 更新日: 2026-09-19。試作中は既存契約を維持する。新方式の本体契約は試作評価後に詳細化する。

## 1. 現行実装と旧設計

[旧API設計](./legacy-video/03-api-design.md)は既存動画スタブを理解するための参照資料。全記述が実装済みという意味ではない。実際の契約は[OpenAPI](../backend/openapi.json)、実際のDB変更は[Flyway migration](../backend/src/main/resources/db/migration)を参照する。

## 2. 3D試作と採用後の変更

試作は既存認証の内側に専用ページを追加し、固定素材を使う。投稿APIを呼んで試作音声を生成しない。新しいrequestAvatar等の名前はまだ確定していない。

本体移行時に、発話希望のリクエスト、音声生成状態と表示資格、モデル設定/クレジット、履歴再生、既存requestVideo/videoDecision/videoUrlとVIDEO_*状態の互換性・廃止手順を定める。OpenAPIとフロント生成型を同時に更新する。無料投稿、冪等キー、停止・削除・所有者認可の契約は維持する。

具体化していない部分を旧動画契約の単純な名称変更で埋めない。新規実装の優先順位は [07](./07-operations.md) に従う。
