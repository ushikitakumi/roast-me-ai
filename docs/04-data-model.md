## 1. 現行実装と旧設計

## 2. 3D試作と採用後の変更

試作の固定モデル・音声は設定と素材で扱い、DBの新しいマイグレーションは今回追加しない。既存のFlyway V1〜V3、動画スタブ状態、費用台帳を維持する。適用済みマイグレーションを新方針に合わせて書き換えない。

本体移行前に、モデル資産/形式/版/利用条件/クレジットとモデル固有の口・表情設定をどこに持つか、生成音声と履歴の関連、モデル差し替え後の過去の再生、旧video_keyとVIDEO_*状態をどう扱うかを設計する。人格・声・見た目を分離し、自作モデルへの差し替えに備える。新しいテーブル名やスキーマは未確定。

本文の表示資格と生成状態、入力参照、削除と独立した費用台帳、日本時間の集計・不明予約の保持は維持する。

具体化していない部分を旧動画契約の単純な名称変更で埋めない。新規実装の優先順位は [07](./07-operations.md) に従う。
